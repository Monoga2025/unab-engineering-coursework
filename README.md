# UNAB Engineering Coursework

My own study notes, problem solutions, CAD exercises and small study tools from the mechatronics engineering program at UNAB. It is a record of what I built while learning: kinematics and mechanism design, CAD modeling, waves and particles lab work, electrical circuits, and a few study web tools.

## What is included

- `carrera-mecatronica/Mecanismos/`: mechanism exercises (Geneva cross, crank-slider, four-bar and three-position linkages) with some MATLAB scripts.
- `carrera-mecatronica/Dibujo_Asistido/`: SolidWorks part and assembly exercises from the drawing course, including a radial engine model.
- `carrera-mecatronica/Ondas_Particulas/`, `Circuitos_Electricos/`, `Mecanica/`: study guides written in Markdown.
- `carrera-mecatronica/Herramientas_web/`: small HTML study tools (lab simulator, workshop guide, a quiz trainer) and a notebook generator script.
- `estudio-unab/`: a short index note for the study folder.

## Stack

- SolidWorks (`.SLDPRT`, `.SLDASM`), STEP/IGES exports, MATLAB (`.m`), Python, HTML/JavaScript, Markdown.

## What was removed on purpose

- Course PDFs, handouts and lecture recordings (copyrighted course material).
- Classmates' work and any file that carries a student ID or someone else's personal data.
- Email classification tooling, automation exports with credentials, and agent configuration files.
- Archives (`.rar`, `.zip`) of unknown content, videos, and files over 8 MB.

## Honest status

- Coursework in progress. Solutions are not guaranteed to be correct. Verify before reuse.
- Exercise PDFs referenced in the notes are not included.
